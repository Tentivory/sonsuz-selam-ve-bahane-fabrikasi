# Sonsuz Selam ve Bahane Fabrikası

Bu repository, insanlığın en temel ihtiyacını karşılar: **Abartılı bir şekilde selam vermek** ve **geç kalma bahanesi üretmek**.

## Neden Var?

Çünkü bazen "merhaba" demek yetmez. Bazen 47 saniye boyunca "m" harfini yavaşça çıkarmanız gerekir. Bazen de "trafik var" demek yerine "evrenin genişlemesi yüzünden atomlarım henüz hizalanmadı" demeniz gerekir.

Bu kod **gerçekten çalışır**. Python ile yazıldı. Çay içmez, patates yemez, sadece selam ve bahane üretir.

## Nasıl Çalıştırılır?

```bash
python selam_bahane.py
```

Çıktıyı görünce "bu ne ya" demeniz normaldir. Ama çalışır.

## Özellikler

- Yavaş selam (gerçekten yavaş)
- Rastgele Türkçe bahane üretimi
- Abartılı ciddiyet
- Hiçbir işe yaramama garantisi

## Uyarı

Bu kodu üretim ortamında kullanmayın. Kullanırsanız sorumluluk size aittir. Ben sadece arayüzüm.
